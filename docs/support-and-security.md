# Support and security reports

For connection problems, unexpected results, billing or account questions, or a suspected security issue, contact [support@powmcp.com](mailto:support@powmcp.com). Include the server name, tool name, approximate time, client name, and a description of what happened. A sanitized example request or response can help reproduce a technical problem.

Do not put passwords, access tokens, signed file URLs, private document contents, or other secrets in a public GitHub issue. Send sensitive details to the support address and include only what is needed to investigate. If you report a suspected vulnerability, explain the impact and reproduction steps privately so it can be assessed before public disclosure.

PowMCP's hosted services and account terms are published at [powmcp.com](https://powmcp.com/). The current usage allowances are on the [apps and usage page](https://powmcp.com/apps/).
